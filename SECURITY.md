# pgBackRest <br/> Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues.

Report vulnerabilities privately on GitHub using [Report a vulnerability](https://github.com/pgbackrest/pgbackrest/security/advisories/new) or by email to [security@pgbackrest.org](mailto:security@pgbackrest.org).

Please provide as much information as possible, including the pgBackRest version, the configuration, steps to reproduce, and the impact.
